# Pitch (HTML version)

Open `index.html` in Chrome (double-click works, no internet needed). Press `F` for full screen.

| Key | Action |
|---|---|
| Right arrow, Page Down, Enter, clicker "next" | Next slide |
| Left arrow, Page Up, Backspace, clicker "previous" | Previous slide |
| Space, or click the video | Pause / resume the video on this slide (on slides without a video, Space = next slide) |
| Home / End | First / last slide |
| F | Full screen on / off |

- Each video plays once from the start when you arrive on its slide, and stops on its last frame.
- Going back to a video slide restarts its video.
- A "PAUSED" label shows at the bottom-left while a video is paused (it is only on the presenter screen, never inside the video).
- Keep the `assets` folder next to `index.html`.
- Source of the slides: the "PV Automation Pitch" deck in claude.ai. If the deck changes, this folder has to be rebuilt.
